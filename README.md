# AI Agent Gwy

基于 OpenCode 构建的公务员/事业单位考试多代理辅导项目。

当前版本重点实现了行测场景下的多代理协作辅导：由编排器识别用户意图，路由给对应老师/学生代理，并结合自定义工具完成出题、计时、判题、积分和学习数据记录。

## 项目功能

### 1. 多代理协同辅导

- `orchestrator` 作为中央编排器，负责识别用户意图、选择代理、调用工具并整合结果。
- 支持多角色联合回答，输出结构为“角色发言 + 总结结论”。
- 老师代理负责方法讲解、题型拆解、知识点归纳。
- 学生代理负责从上岸考生视角补充备考经验和实战建议。

当前已配置代理包括：

- `xingce-zong-teacher`：行测总老师，提供全局方法论和跨模块策略
- `xingce-yanyu-teacher`：言语理解与表达
- `xingce-shuliang-teacher`：数量关系
- `xingce-panduan-teacher`：判断推理
- `xingce-ziliao-teacher`：资料分析
- `xingce-changshi-teacher`：常识判断
- `xingce-zhengzhi-teacher`：政治理论
- `guokao-champion`：国考状元视角
- `chongqing-champion`：重庆省考状元视角

### 2. 行测答疑与讲解

- 用户可以直接发题目或描述知识点问题。
- 编排器会按题目类型路由到对应模块老师。
- 在需要时，会同时召集总老师和状元学生代理，从方法、策略、备考经验三个层面给出答案。

### 3. 智能出题练习

- 支持按科目出题，也支持不指定科目时自动出题。
- 对有学习记录的用户，会优先根据薄弱项推荐练习科目。
- 当前出题以单项选择题为主，要求包含：题目、A/B/C/D 四个选项、正确答案、详细解析。

当前支持的练习科目包括：

- 言语理解与表达：逻辑填空、片段阅读、语句表达
- 数量关系：数学运算
- 判断推理：图形推理、定义判断、类比推理、逻辑判断
- 资料分析：资料分析
- 常识判断：法律、经济、科技与生活、人文与历史、国情地理、管理与公文
- 政治理论：政治理论

### 4. 计时、判题与训练闭环

- 出题后可启动基于 attempt 的计时器，记录答题用时并绑定当前练题会话。
- 支持查看计时状态、停止计时、放弃当前计时。
- 客观题可自动判题。
- 主观题已预留判题入口，目前返回“需要老师评判”。
- 新链路下，计时、判题、积分与 mastery 结算共享同一个 attempt 状态，避免重复写入。

### 5. 用户档案与学习画像

- 首次使用可自动创建用户档案。
- 用户数据保存在 `data/users/` 下，不进入 git。
- 用户画像会持续记录创建时间、积分等级、连胜情况、各科目正确率、平均耗时、细分题型数据和历史答题记录。

### 6. 积分与等级系统

- 答对加分，答错扣分。
- 自动维护连续正确次数和历史最佳连胜。
- 根据积分自动计算等级。
- 支持查询当前等级进度和距离下一级所需积分。

## 当前已实现的用户流程

1. 用户进入对话，创建或加载个人档案
2. 用户提问、练题或查询进度
3. 编排器选择合适的老师/学生代理参与回答
4. 若为练题场景，则调用出题、计时、判题、积分工具形成以 attempt 为核心的完整闭环
5. 最终返回整合后的讲解、结果和学习建议

## 核心工具

项目当前实现了 5 个核心 coaching tools：

- `user-profile`：用户档案创建、读取、统计、做题记录更新
- `timer`：答题计时
- `grading`：判题
- `question-generator`：按科目或薄弱项生成出题模板
- `points`：积分和等级管理

## 技术实现

- 基于 OpenCode Agent 配置驱动多代理协作
- 自定义插件使用 `@opencode-ai/plugin`
- 通过本地 JSON 文件持久化用户学习数据
- 通过编排器实现“意图识别 -> 代理路由 -> 工具调用 -> 结果整合”的交互链路
- 通过 `.opencode/rules/` 统一共享考试上下文、练题闭环和输出格式规则
- 由于当前 custom tool 在 `permission` 下的等价访问语义尚未验证完成，`opencode.json` 仍临时保留 orchestrator 的 `agent.tools` 配置作为兼容例外

## 当前范围说明

当前仓库的实际实现重点在 Phase 1：

- 行测答疑
- 行测练题
- 学习进度统计
- 积分与等级反馈

以下方向在项目规划中，但当前版本尚未完整落地：

- 申论完整辅导
- 事业单位考试完整辅导
- 更完整的主观题评分体系
- 更丰富的学习计划与长期训练编排

## 适用场景

- 公务员考试行测刷题与答疑
- 按薄弱模块进行针对性训练
- 结合成绩、耗时和连胜情况做学习跟踪
- 通过多角色视角获得更立体的备考建议
