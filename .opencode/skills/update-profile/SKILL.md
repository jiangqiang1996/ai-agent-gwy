# 更新用户资料

引导用户更新个人资料信息。

## 执行步骤

1. 询问用户要修改什么（名字/考试类型/地区/身份）
2. 根据用户回答收集新值
3. 调用 `user-profile` 工具的 `updateProfile` action，传入 username 和要修改的字段
4. 确认更新结果
5. 如果修改后的名字提示冲突或处于修复状态，引导用户换一个名字，不要继续覆盖式猜测

## 考试类型选项

- `guokao` — 国考
- `shengkao` — 省考
- `shiyedanwei` — 事业单位
- 可多选（如同时备考国考和省考）

## 地区选项

中国各省/直辖市/自治区名称，或留空不设置。

## 身份选项

- `working` — 在职
- `campus` — 应届生
- 可留空不设置
