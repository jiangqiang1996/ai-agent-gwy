# 内联 HTML 资源

将已有的 HTML 导出文件中所有引用的资源（本地图片、CSS、JavaScript、字体等）内联为 data: URL 或内嵌标签，生成一个独立的单文件离线包。

## 触发条件

**仅在用户明确要求时触发**，常见表达：
- "把这个 HTML 的资源内联"
- "内联 HTML 资源"
- "把 HTML 变成单文件"
- "生成离线版 HTML"
- "把导出的 HTML 打包成单文件"

**不要**在普通导出流程中自动触发此功能。

## 执行步骤

1. 确认用户明确要求内联 HTML 资源。
2. 确定目标 HTML 文件路径：
   - 用户明确指定了文件路径 → 使用指定路径。
   - 用户没有指定 → 使用本轮对话中最近一次 HTML 导出的结果文件。
   - 如果找不到可内联的 HTML 文件，提示用户先导出 HTML 或提供文件路径。
3. **立即**调用 `inline-html-resources` 工具，参数：`htmlFilePath=<步骤2的路径>`。
4. 工具返回后，告诉用户内联结果和文件位置。

## 行为说明

- 工具会读取原始 HTML 文件，验证所有引用资源的可访问性。
- 验证通过后，将资源内联并写入同目录下的 `*-inlined.html` 文件。
- **原始 HTML 文件保持不变**，内联结果是独立的新文件。
- 如果任何引用资源不可达（本地文件缺失或远程 URL 无法访问），操作失败，不产生半成品文件。
- 已经是 `data:` URL 的资源保持不变，不会重复处理。

## 关键注意

- **不要**在普通导出时自动内联，这是独立的显式工作流。
- **不要**用 `write` 工具或 `bash` 写文件，必须用 `inline-html-resources` 工具。
- 内联操作前需要所有资源可访问，确保网络通畅（如有远程资源）。
- 内联后的 HTML 文件体积通常比原始引用模式大很多。
