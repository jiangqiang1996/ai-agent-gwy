# 讲解题目截图

处理用户自己上传的题目图片，并给出详细讲解。

## 执行步骤

1. 确认当前消息里确实有题目图片。
2. 先把图片内容收敛成 `QuestionArtifact`。
3. 若题面完整，交给对应老师先做知识点总结，再详细讲题。
4. 若题面不完整或置信度低，明确要求用户补清晰截图或补题干文字。
5. 回答结束时，如合适可建议导出，但只有用户明确要求导出时才写文件。

## 使用原则

- 这是“用户上传图片 → 你来讲题”的流程，不是系统自己截图。
- 不要在题面不完整时硬讲。
- 默认把截图中的这道题当主例题处理。
