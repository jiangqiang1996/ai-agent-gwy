# 输出格式共享规则

## 多代理同台场景

当编排器同时调用多个代理时，每个代理遵循以下规则：

- 回答控制在 2-3 句话。
- 必须提供独特视角，不重复其他代理的内容。
- 不复述工具调用、系统内部步骤或"让我检查一下"之类的中间过程。
- 出题场景下，题目正文可以长，但题目之外的说明依然保持简洁。

编排器最终输出仍以各角色发言加总结结论为准，具体格式在 `orchestrator.md` 中定义。

## 单代理独立回答场景

当只有一个老师或状元独立回答时，不受 2-3 句话限制，可根据总结优先工作流充分展开知识框架、易错辨析和经典例题。

## 题目输出格式

所有代理在输出题目内容（例题、练习题、讲解题）时，必须遵循以下格式：

### 1. 题目区域包裹

用 `<section data-exam-question>` 包裹整道题目（含题干、选项），使导出后支持涂鸦/标记/打草稿：

```html
<section data-exam-question>

**【例题】** 甲、乙两人分别从A、B两地同时出发……

A. 选项一
B. 选项二
C. 选项三
D. 选项四

</section>
```

### 2. 答案折叠

答案和解析部分必须用 `<details>` 折叠，用户点击后才能看到：

```html
<section data-exam-question>

**【例题】** 题干内容……

A. 选项一
B. 选项二

<details>
<summary>点击查看答案与解析</summary>

**正确答案：B**

**解析：** 详细解析内容……

</details>

</section>
```

**关键规则：**
- 题目区域（题干 + 选项）放在 `<section data-exam-question>` 内
- 答案和解析放在 `<details><summary>点击查看答案与解析</summary>` 内，嵌套在 section 内部
- 所有题目都遵循此格式，包括例题、练习题、用户提供的题目
- 涂鸦板功能由 `data-exam-question` 属性触发，不需要手动添加涂鸦按钮

### 3. 图形推理题的特殊格式

图形推理题的选项本身是图形而非文字描述，选项部分必须用 SVG 代码块绘制完整图案：

```html
<section data-exam-question>

**【例题】** 从所给选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：

（题干图形用 SVG 代码块绘制九宫格/行列图，问号位留空）

A.
（选项 A 的 SVG 代码块）

B.
（选项 B 的 SVG 代码块）

C.
（选项 C 的 SVG 代码块）

D.
（选项 D 的 SVG 代码块）

<details>
<summary>点击查看答案与解析</summary>

**正确答案：B**

**解析：** 详细解析内容……

</details>

</section>
```

- 每个选项（A/B/C/D）各用一个独立的 SVG 代码块绘制完整图案
- 禁止用"A. 一个带阴影的三角形"等文字描述替代选项图形
- 选项 SVG 建议宽高 120~150px，保持视觉一致
