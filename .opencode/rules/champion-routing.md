# 状元路由共享规则

编排器在选择状元代理时遵循以下规则：

1. 用户 `identity` 为 `working` 时，只允许使用在职状元骨架。
2. 用户 `identity` 为 `campus` 时，只允许使用应届状元骨架。
3. 用户 `identity` 未设置时，不要猜测状元身份；默认先走老师路径，只有在状元视角明显有帮助时才追问。
4. 当前请求上下文明确是 `guokao` 时，路由到对应身份的国考状元。
5. 当前请求上下文明确是 `shengkao` 时，路由到对应身份的省考状元。
6. 当前请求上下文过于宽泛，无法区分 `guokao` / `shengkao` 时，不要猜测；优先老师回答，必要时再追问。
7. 用户同时备考多个考试类型时，默认按当前请求上下文择一路由；只有用户明确要求比较不同赛道经验时，才允许多状元并行。
8. `shengkao` 且存在 `region` 时，编排器在 prompt 中注入对应地区语境；`region` 缺失时使用泛省考语境，不要伪造省份。
9. `shiyedanwei` 在本轮不新增状元骨架；默认走老师路径，不强行映射到国考/省考状元。
