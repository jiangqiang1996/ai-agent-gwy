# 导出工作流共享规则

## 核心原则

- 只有在用户明确要求导出时才写文件。
- 导出目标统一为项目根目录 `output/`。
- 系统可以建议导出，但不能自动写文件。
- **所有导出一律先写 .md 文件，HTML 只能从已有的 .md 文件转换生成。**

## 导出流程

用户要求导出时，按以下步骤执行：

1. **提取 content**：按下方 content 提取规则收集要导出的内容。
2. **调用 `export-document` 工具**：传入 `content` 和可选的 `title`，工具会写入 .md 文件到 `output/`。
3. **判断是否需要 HTML**：
   - 用户说"导出"且未指定格式 → 告知 .md 路径，提示"已导出 Markdown 文件，是否需要转换为 HTML（带公式渲染、图表、涂鸦板等交互功能）？"
   - 用户说"导出html" / "导出成html" / "保存为html" → **立即**调用 `convert-md-to-html` 工具，传入步骤 2 返回的 .md 文件路径
   - 用户说"导出markdown" / "导出成md" → 仅保留 .md，不转 HTML
4. **转 HTML 时加载 skill**：需要转 HTML 时，加载 `export-html` skill（包含扩展语法指南），按 skill 中的执行步骤调用 `convert-md-to-html` 工具。

## .md → HTML 转换场景

以下场景**应建议用户转 HTML**（在导出 .md 后提示）：
- 内容包含 Canvas 动态绘图（` ```canvas ` 代码块）
- 内容包含 Chart.js 数据图表（` ```chart ` 代码块）
- 内容包含 SVG 图形（` ```svg ` 代码块）
- 内容包含思维导图 / 知识图谱（` ```markmap ` / ` ```mindmap ` / 复杂 Mermaid 图）
- 内容包含交互组件（Tab 切换 `<div class="tabs">`、折叠 `<details>`、Tooltip `<span class="tip">`）
- 内容包含图片（题图、`![...]()`）
- 内容包含 `data-exam-question` 标记（涂鸦板）

HTML 转换默认按"**验证引用优先**"处理：本地图片、CSS/JS 运行时库和字体作为独立资源文件写入 HTML 的同级资源目录，转换前逐一验证可访问性；远程 URL 在转换时验证可达性但不内联。转换结果为 HTML 文件 + 同级资源目录的完整包，**必须一起移动才有效**。如需单文件离线包，用户需在转换后显式请求内联 HTML 资源操作。

## 目录（TOC）自动生成规则

- 当内容包含 **2 个及以上标题**（`##` / `###` / `####`）时，转换 HTML 时自动生成侧边栏目录，无需手动添加。
- 仅 1 个标题或无标题时不生成目录。
- 目录支持滚动高亮和点击跳转，LLM 不需要在 content 中手写目录结构。

## content 提取规则

1. 用户明确指定了要导出的内容 → 直接用。
2. 用户没指定 → 取本轮对话中**最近一次老师/状元的回答正文**。
3. content 只保留实质内容（知识点、讲解、例题），不包含工具调用、确认过程或系统消息。
4. **不要**在调用工具前反复确认，收集到 content 后立即调用。

## 题目区域涂鸦板（Scratchpad）

- 当转换的 HTML 内容中包含带有 `data-exam-question` 属性的 HTML 元素时（如 `<section data-exam-question>题目内容</section>`），转换器会自动注入涂鸦板功能。
- 涂鸦板仅在标记区域内激活，不影响其他内容的阅读、选择和滚动。
- 涂鸦板功能为临时性，刷新或重新打开页面后自动消失，不会持久化。
- 如果 HTML 中没有任何 `data-exam-question` 标记，转换正常进行，不会注入涂鸦板相关资源。
- 涂鸦板以鼠标操作为主，触控/手写笔为辅助。

## 内联已有 HTML 资源

- 内联 HTML 资源是一个**独立的工作流**，只在用户明确要求时触发（如"把这个 HTML 的资源内联"）。
- 它不会在默认导出流程中自动执行。
- 该功能通过 `inline-html` skill 触发，详见 `.opencode/skills/inline-html/SKILL.md`。
- 内联时，所有引用的资源（本地文件、远程 URL）都必须验证可访问，任何资源不可达则失败并给出明确提示，不产生半成品文件。

## 性能预算

- .md 文件写入：p50 < 50 ms。
- HTML 转换（≤20 个引用资源）：p50 < 500 ms，p95 < 1.5 s（不含文件系统冷启动）。
- 含远程资源时：远程验证总耗时上限 5 s（受并发和超时约束）。
- 内联已有 HTML：p95 < 10 s，仅限用户显式触发，不影响默认导出速度。
- 无 `data-exam-question` 标记的文档不注入涂鸦板资源。
- 默认转换不会将运行时库或图片内联到 HTML 正文中，不会在单次转换中重复复制相同资源。

## 关键禁止

- **不要**用 `write`、`edit` 或 `bash` 写文件，必须用 `export-document` 或 `convert-md-to-html` 工具。
- **不要**自己把 Markdown 转成 HTML 再传 content，始终传原始 Markdown。
- **不要**跳过 .md 步骤直接生成 HTML，HTML 只能从已有 .md 文件转换。
