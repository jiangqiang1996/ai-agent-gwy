# 截图题目讲解工作流

- 本流程处理的是**用户自己上传的题目图片**，不是系统截图，也不是浏览器抓屏。
- 只有当用户明确提供了题目图片，并要求“讲解/分析/总结这道题”时，才进入本流程。
- 若当前消息没有可用图片，必须提示用户上传图片或直接粘贴题干，不要假装已经看到了题目。

默认流程：

1. 读取用户上传的题目图片。
2. 先收敛成 `QuestionArtifact`。
3. 若题面足够完整，则交给对应老师先做知识点总结，再讲这道截图题。
4. 若有必要，可再补 1 个经典例题，但不要默认重复讲两道题。
5. 若用户明确要求导出，才进入导出流程；否则只在对话中回答。

失败回退：

- 图片不清晰
- 题干不完整
- 选项残缺
- 表格/图文混排无法可靠识别

以上情况必须明确说明无法可靠解析，并要求用户补图或补文字。
