# 地区与考试类型感知的个性化辅导

## Problem Frame

当前系统对所有用户使用统一的行测科目和通用教学策略。实际上，国考、省考、事业单位的考试科目和侧重点差异显著，不同省份还有特殊科目。用户需要针对自己报考的考试类型和地区获得差异化辅导——包括出题范围、考情分析、学习计划三个维度。不提供地区/考试类型的用户仍可使用通用策略。

## Requirements

**用户档案扩展**

- R1. UserProfile 增加 `examTypes`（考试类型数组，支持多选）和 `region`（地区/省份）字段，均为可选。已有档案加载时需补填默认值（空数组/null），确保旧数据兼容
- R2. 考试类型枚举：`guokao`（国考）、`shengkao`（省考）、`shiyedanwei`（事业单位）。`examTypes` 为数组，可同时选多项（如同时备考国考+省考），出题取科目并集
- R3. 地区为中国省份/直辖市枚举，支持"不限"或空值表示未指定
- R4. 首次交互时收集姓名（必填）、考试类型（选填，可多选）、地区（选填），一次性询问。`loadOrCreate` 支持传入可选的 `examTypes` 和 `region` 参数
- R5. 提供"设置/更新资料"技能 + `user-profile` 工具新增 `updateProfile` action，允许用户随时修改姓名、考试类型、地区

**考试配置数据**

- R6. 结构化配置定义每种考试类型的科目列表、出题权重、难度倾向（硬事实，配置驱动）
- R7. 配置覆盖地区特殊科目（如广东科学推理、上海政法等）
- R8. 地区考情侧重（如某省数量关系占比高、某省常识偏法律等）不单独配置，由编排器在路由时将考试类型+地区作为上下文传给老师代理，由 AI 自适应提供考情建议
- R9. 未指定考试类型/地区时，使用通用配置（全部行测科目、均等权重）

**出题差异化**

- R10. question-generator 根据考试类型和地区调整出题的科目范围和权重分配。科目验证改为从动态考试配置读取，不硬编码科目白名单
- R11. 不属于任何已选考试类型的科目软降权（极低权重但仍可出题），而非硬排除。多选考试类型时取科目并集
- R12. 地区特殊科目纳入出题范围

**考情分析**

- R13. 编排器支持"考情分析"意图路由，将考试类型和地区信息传给老师代理
- R14. 老师代理根据地区和考试类型给出针对性的考情侧重分析和备考建议

**学习计划**

- R15. 编排器支持"制定学习计划"意图路由，综合考试类型、地区、用户画像（mastery 数据）生成个性化学习计划
- R16. 每次会话开始时（用户已有档案），编排器主动给出简短学习建议（1-2 句话），基于考试类型、地区、薄弱科目
- R17. 用户请求详细学习计划时，给出完整版（科目优先级、时间分配建议、薄弱项强化路径）
- R18. 生成的学习计划存储到用户档案中，下次会话时可对比学习进度与计划

## Success Criteria

- 用户设置考试类型为"事业单位"后，不相关科目权重极低
- 用户同时选国考+省考后，出题覆盖两种考试的科目并集
- 用户设置地区为"广东"后，出题包含科学推理等特殊科目
- 用户请求考情分析时，老师代理能给出该地区该考试类型的针对性建议
- 用户请求学习计划时，系统结合 mastery 数据和考试类型给出个性化建议，计划可跨会话对比
- 未设置考试类型/地区的用户，体验与当前一致（通用策略）

## Scope Boundaries

- 不实现真实考试报名、缴费、准考证等功能
- 地区考情数据为配置（科目/权重）+ AI 上下文（考情侧重）混合，不保证 100% 准确性
- 不区分同一省份不同年份的考情变化（使用当前/近期趋势）

## Key Decisions

- **混合方案（配置 + AI 上下文）**：科目列表和出题权重用结构化配置保证准确性，考情侧重由编排器上下文传递给 AI 代理自适应
- **首次交互一次收集**：姓名必填，考试类型和地区选填，降低用户门槛
- **技能 + 工具双重支持**：用户可通过"设置资料"技能触发，底层由 `updateProfile` 工具 action 实现持久化
- **未设置时降级为通用策略**：保证不提供地区/考试类型的用户也能正常使用
- **支持多选考试类型**：允许用户同时备考多种考试，出题取科目并集
- **软降权而非硬排除**：非考试科目降权到极低但不为零，用户仍可主动练习
- **学习计划跨会话存储**：生成的计划写入用户档案，支持进度对比

## Dependencies / Assumptions

- 老师代理需要能理解编排器传入的考试类型和地区上下文
- 考试配置数据（科目列表、权重）需要持续维护
- AI 代理的考情知识准确性依赖模型能力，非硬编码保证
- `updateProfile` action 需要处理文件名变更（如果用户改名）
